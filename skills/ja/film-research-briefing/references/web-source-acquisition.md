# YouTube・ブログ資料の取得

## 共通手順

1. 検索結果から候補 URL を得る。
2. URL の原ページを開き、題名、作成者、公開日、更新日、対象作品を確認する。
3. 実際の本文、動画、字幕またはトランスクリプトを確認する。
4. 主張ごとにページ節、段落見出し、タイムコード等の evidence anchor を残す。
5. 出典ノートには忠実な要約と必要最小限の短い引用だけを保存する。

検索スニペット、AI 検索要約、動画タイトル、サムネイルだけを `grounded` としない。

## YouTube

- チャンネル名と動画の話者を区別する。ゲストの発言は話者へ帰属する。
- 字幕が投稿者作成か自動生成かを記録する。自動字幕は固有名詞、否定、数値を動画音声で再確認する。
- タイムコードは `HH:MM:SS` または `MM:SS` で残す。
- 動画説明欄の主張と動画内の発言を区別する。
- トランスクリプトを取得できなければ、視聴して確認した範囲だけをノート化する。視聴もできない場合は `metadata-only` とし、内容を推測しない。
- 年齢・地域・ログイン制限、CAPTCHA、有料壁、削除動画を迂回しない。同一方法の反復取得を止め、別資料または利用者提供資料へ切り替える。

## ブログ・Web 記事

- 著者名、媒体、公開日、最終更新日、引用元リンクの有無を確認する。
- あらすじ、引用、筆者の解釈を分けてノート化する。
- 参照している一次資料があれば、可能な範囲でその一次資料へ遡る。
- 動的ページや削除リスクのあるページは取得日を必ず記録する。保存はサイト規約と権利を尊重し、原則として URL、メタデータ、短い証拠箇所、要約に留める。

## 翻訳

原言語の証拠箇所と日本語要約を分ける。重要語は原語を併記し、字幕版・吹替版・独自訳を混同しない。訳に判断が入る場合はその旨を記す。
