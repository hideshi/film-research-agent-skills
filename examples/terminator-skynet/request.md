# 利用例: ターミネーターとスカイネット

```text
$film-research-briefing の sf-futures 主プロファイルと philosophy-ethics 補助タグを使い、『ターミネーター』（1984年）のスカイネットを、
5分で理解できる日本語ブリーフィングにしてください。全編ネタバレ可です。
スカイネットとは作中で何なのか、この未来像のどこが今も想像力を刺激するのか、
この作品からどんな未来への問いが生まれるのかを知りたいです。

YouTube 解説、ブログ、批評・研究資料を探索して構いません。ただし、
作品内の事実、世界設定、制作者の発言、解説者の解釈、あなたが導いた問いを分け、
各主張を出典ノートへ追跡できるようにしてください。作品本編を確認できない
場合は明記し、映像表現について断定しないでください。

私の過去の論文や研究テーマには接続しないでください。
```

このファイルは依頼例であり、作品についての事実主張や完成済み調査結果ではない。
